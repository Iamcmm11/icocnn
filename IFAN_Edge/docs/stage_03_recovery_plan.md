- “当前 IFAN 是否还是旧简化主干”

- 主干重构目标已完成。

- 是否需要更大评测口径验证当前结论稳定性
- 何时进入 LOCATA 单源任务验收

## 5. 新的收尾路线

后续不再沿用“先怀疑主干、再怀疑前端”的旧恢复顺序，而是统一改为：

1. 用当前完整主线做论文口径差距分析
2. 判断是否需要更长训练预算
3. 判断是否需要更大评测口径
4. 准备 LOCATA 单源任务验收
5. 只在新证据出现时，才回头看剩余结构歧义

## 6. 当前最小行动集合

| 动作 | 回答的问题 | 优先级 |
| --- | --- | --- |
| 更长训练预算验证 | 当前 `40 epoch` 是否已到上限 | 高 |
| 更大评测口径验证 | 当前“接近 baseline”的结论是否稳定 | 高 |
| LOCATA 单源任务准备 | 当前是否真正接近论文级复现 | 高 |
| `frequency_block` vs reference 长训练对比 | LMS 近似误差是否仍会影响上限 | 中 |
| `final_head_pooling` 尾部验证 | 是否还存在小的结构收益点 | 中 |

## 7. 暂停条件

以下情况出现时，需要先复盘，再继续推进：

- 若更大评测口径下结论明显反转
  - 先修正评测结论，不进入 LOCATA
- 若更长训练仍无改善
  - 优先回到论文口径或 LMS 近似实现分析
- 若 LOCATA 单源任务结果明显背离模拟实验趋势
  - 优先检查数据口径与验收流程，而不是回退到旧简化主干叙事

## 8. 当前行动摘要

1. 主干正确性问题已经基本收口。
2. 旧简化主干实验不再作为 IFAN 复现证据。
3. 阶段 3 当前任务已经从“恢复正确主干”切换为“解释剩余论文差距”。
4. 后续重点是更长训练、评测口径稳定性与 LOCATA 验收，而不是回到旧结构怀疑链。
