# 阶段 03 剩余差距分析提纲

## 目标

本文档用于分析：

- 为什么完整重构后的 IFAN 主线已经接近 `icoCNN r=2` baseline，但仍与论文最好结果存在剩余差距
- 接下来应该优先怀疑哪些论文口径差异，而不是回到“主干可能没复现对”的旧叙事

本文档只整理当前有效现象、优先级和建议验证，不再把旧简化主干阶段的实验当作证据来源。

## 证据边界

- 只有完整重构后的 IFAN 主线结果才计入本分析文档：
  - `outputs/stage3/ifan_stage3_full20_freqblock_paper_original_20260419_005314`
- 旧简化主干、重构前主干、未完整复现架构阶段的实验：
  - 只保留为历史排障背景
  - 不再作为当前差距分析的依据

## 当前已知现象

基于当前有效主结果：

- `best_val_rmsae_deg = 6.6669847294688225`
- `final val_rmsae_deg = 7.358573332428932`
- 四场景对比：
  - `IFAN mean RMSAE = 8.170234978199005 deg`
  - `icoCNN mean RMSAE = 7.8069010972976685 deg`
  - `delta = +0.36333388090133667 deg`
- 高混响低 SNR 两场景：
  - `IFAN mean RMSAE = 9.679717183113098 deg`
  - `icoCNN mean RMSAE = 9.469039112329483 deg`
  - `delta = +0.2106780707836151 deg`
- 分场景：
  - `scene_1` 已优于 baseline
  - `scene_2 / scene_3 / scene_4` 仅小幅落后 baseline

直接观察：

- 当前 IFAN 已经不是“全场景显著落后 baseline”的状态。
- 当前结果已经足以说明完整主干方向是对的，旧简化主干不再具备分析价值。
- 当前差距的量级更像：
  - 论文口径剩余差异
  - 训练预算与评测预算差异
  - LMS 近似实现与论文行为仍未完全等价
  - LOCATA / 模拟实验验收尚未补齐

## 当前最值得优先回答的四个问题

### 问题 1：论文评测口径和当前工程口径是否还有剩余偏差

- 当前四场景评测是否完全覆盖论文模拟实验的真实验收方式
- RMSAE 计算、前 5 帧剔除、固定验证 cache 的使用方式是否与论文完全一致
- 当前 baseline checkpoint 是否与论文中对比口径完全同源

### 问题 2：当前训练预算是否已经足够代表这条主线的上限

- 当前 `40 epoch` 是否只是“已接近收敛”，而不是“已到上限”
- `epoch 20` 达到最优后，后 20 轮基本持平，说明当前曲线已经很稳，但是否仍需要更长训练或更大数据预算验证

### 问题 3：`frequency_block` 虽然足够快，但是否与论文时域 LMS 仍存在小的行为差异

- 当前 backend 路线已经足够支持训练
- 但论文原始 LMS 行为仍是参考实现
- 若想继续逼近论文结果，需要进一步确认近似误差是否会在长训练中积累到可见量级

### 问题 4：当前差距是否已经转移到论文级验收而非主干正确性

- 当前已经没有足够证据继续把问题归因到“IFAN 主干仍是错的”
- 更合理的下一步是：
  - 验证论文口径
  - 做更长预算验证
  - 准备 LOCATA 单源任务验收

## 优先级调整

当前优先级应调整为：

1. 论文口径与评测口径对齐
2. 训练预算与收敛边界验证
3. LMS backend 近似等价性与长训练稳定性验证
4. LOCATA 单源任务验收准备
5. 最后才考虑剩余结构歧义

原因：

- 当前结果已经足够接近 baseline，不再支持“主干可能仍错得很离谱”的判断。
- 结构问题如果仍存在，也更可能是小的尾部歧义，而不是决定成败的主因。
- 当前最缺的是“为什么和论文最好结果还有差距”的解释，而不是“为什么旧简化主干失败”的复盘。

## 分析模块 A：论文口径对齐

### 需要确认的问题

- 当前四场景是否只是工程对比集，而不是论文正式模拟验收全集
- 当前 validation cache 与 scenario cache 的大小是否足以代表论文口径
- 当前 baseline 对比是否和论文使用了同一类测试划分与误差聚合方式

### 判断标准

- 如果口径不一致，应先修正口径，再解读数值差距
- 如果口径基本一致，剩余差距才值得继续归因到训练预算或前端近似

## 分析模块 B：训练预算与收敛边界

### 需要确认的问题

- `40 epoch` 是否已经足够稳定代表当前主线能力
- 更长训练是否能继续压低 `scene_2 / scene_3 / scene_4`
- 当前 `batch=10, micro_batch=1` 的实现是否已足够等价于论文 phase-2 训练行为

### 判断标准

- 如果更长训练没有带来明显改善，当前差距更像口径或前端实现差异
- 如果更长训练仍能继续改善，则当前结果更像“主线已对，但预算还不够”

## 分析模块 C：LMS backend 与近似实现

### 需要确认的问题

- `frequency_block` 与 `time_reference` 的长期训练差异是否足够小
- 当前近似是否只影响极少数 hard scenes，还是对整体都无显著影响
- 是否需要继续保留 reference backend 作为 regression truth

### 判断标准

- 如果主结果对 backend 切换不敏感，则可把当前差距主要归到论文口径或训练预算
- 如果 backend 差异在长训练中会扩大，则应继续围绕 LMS 前端精修

## 分析模块 D：LOCATA 验收缺口

### 需要确认的问题

- 当前模拟实验已经接近 baseline，但 LOCATA 单源任务还没有论文级结果
- 当前是否应先补 LOCATA，再讨论是否真正逼近论文结论

### 判断标准

- 如果 LOCATA 未完成，就不应把“接近 baseline”直接外推成“已基本复现论文效果”
- LOCATA 仍是当前复现闭环中缺失的关键环节

## 当前结论模板

后续继续补分析时，统一按以下格式：

- 有效结果来源：
  - 只写完整重构后主线的输出目录
- 当前现象：
  - 接近 baseline 的具体量化差距
- 已排除项：
  - 主干不是旧简化架构
  - 当前主线可以稳定训练
- 高概率剩余原因：
  - 论文口径 / 训练预算 / LMS 近似 / LOCATA 缺口
- 下一步验证：
  - 对应一个明确实验或文档核对动作

## 当前建议

- 不再继续把旧简化主干实验放进正文分析链。
- 当前分析应围绕“正确主干已经成立，但为何仍未达到论文最好结果”展开。
- 只要没有新的强证据，不再把“主干可能没复现对”列为主假设。
