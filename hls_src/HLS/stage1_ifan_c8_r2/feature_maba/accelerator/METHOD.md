# 面向短序列球面特征的 MABA 硬件实现

## 模型保持不变，改变执行组织

实现对象是 IFAN_Edge 的 FeatureMABATemporalRefiner：240 个球面位置/旋转方向分别形成
8 维时间序列，沿时间进行相同参数的门控递推。空间位置之间不存在状态传播。
本工程不引入标准 Mamba2 的离散化算子，也不将 LayerNorm 换成 RMSNorm。

硬件保持如下顺序：

1. 通道投影 8→16；
2. 核长 3 的因果逐通道卷积，与投影输出相加；
3. 16 维 LayerNorm，epsilon=1e-5；
4. 投影为 8 维候选 q 和 8 维门控 g，alpha=sigmoid(g)；
5. h=alpha*h+(1-alpha)*q；
6. 状态回投影、16 维残差、16→8 输出投影与输入残差。

每次调用重置状态与卷积历史。六帧窗口的独立验证不意味着整网已经实现跨窗口连续推理。
较长序列验证只检查同次调用内的递推与误差，不改变这一接口语义。

## 方法一：位置分块与局部状态驻留

完整张量版本保留输入、投影、混合、归一化、状态投影和状态序列六组主要中间张量。
在 T=6、P=240 下，声明的逻辑容量为
P*T*(8+16+16+16+16+8)*4=460800 字节。
该数量是源代码数组容量，不等于综合后的物理 BRAM 容量；HLS 可能优化、合并或复用存储。

位置块大小为 B 时，阶段张量版本把该容量缩小为 B*T*80*4。
以 B=16 为例是 30720 字节。流水版本进一步只保留块内上下文：

| 对象 | FP32 元素数 | B=16，T=6 时逻辑字节 |
|---|---:|---:|
| DWConv 历史 | B*2*16 | 2048 |
| 门控状态 | B*8 | 512 |
| 输入与输出布局转换缓存 | 2*T*8*B | 6144 |
| 五条数据 FIFO，深度各为 8 | 8*(8+24+24+32+8) | 3072 |

此外存在权重、局部向量、控制通道和综合生成的存储。FIFO 中携带残差数据，保证旁路与主路径
按相同次序到达，不需要另外存储完整时间序列的残差张量。

外部布局仍为 [T,C,R,chart,H,W]，以局部缓冲完成转置；这部分搬运、存储和延迟计入顶层，
不能只统计已经重排好的核心算子。B=32 的最后一块只有 16 个有效位置。

## 方法二：在独立位置间交错时间递推

融合版使用「位置→时间」顺序；交错版改成「时间→块内位置」。
交错后同一位置的相邻时间更新之间存在其他位置的计算，具有隐藏反馈延迟的机会。
这种机会是否转化为吞吐提升取决于投影、归一化和实际调度 II，不能仅凭循环次序判定。
本工程没有用 inter false 等指令否认真实状态依赖。

若消融显示交错没有改善周期，就将其解释为当前瓶颈不在状态反馈，而不能声称该机制有效。
并行度与块大小单独扫描，避免将资源增加的效果记为执行顺序的收益。

## 方法三：利用残差路径的仿射投影折叠

推理时 dropout 关闭：

delta = W_out*(z + W_back*h + b_back) + b_out

将 W_h=W_out*W_back、b_fused=W_out*b_back+b_out 离线预计算后：

delta = W_out*z + W_h*h + b_fused

状态回投影与输出投影部分的 MAC 从 16*8+8*16=256
变为 8*16+8*8=192，减少 25%；这不是整个 MABA 的 25% 加速承诺。
按论文原有每位置每帧 696 的 MAC proxy，此变换减少 64，即约 9.20%。
归一化、非线性、AXI 搬运和流水调度不包含在该 MAC proxy 中。

导出器用固定次序的 FP64 累加计算折叠系数，再舍入为 FP32。
原始检查点不改变，原始 792 参数仍可导入；附加折叠权重为 72 个 FP32 元素。
硬件可以剪除未使用的权重加载，因此接口容量与实际访问量应分别报告。
该变换在实数域等价，在有限精度下不保证逐位一致，必须通过既定误差门限。

## 与公开工作的关系与证据要求

LightMamba 提供算子流式组织、计算重排、细粒度融合与量化的设计参考。
ViM-Q 提供状态计算融合与模块级仿真组织的参考；mamba790m_hls 提供模块验证和残差旁路参考。
本工程独立实现上述 MABA 运算，不复用其特定模型或板卡代码。出处及精确 commit 记录于 references.json。

分块、FIFO 融合、交错与仿射折叠均是已知技术，本工作的可论证贡献是面向
240 条短时间序列、8/16/8 维 MABA 的组合映射及同配置实验。
是否形成足够的论文贡献，应根据实际资源—时延收益与数值结果判断，不把复现改名作为原创。

验收分为软件参考对齐、C 仿真、HLS 综合、RTL 协同仿真四层。
报告分别标明模块误差、替换 MABA 的增量方向误差和整链总误差。
综合估计时钟不是布局布线后的实际频率，模块结果不外推为板级功耗或整网吞吐。
